Feature Roadmap — 5 Sub-Projects

Each gets its own spec → plan → implementation cycle

Build Order (dependency-driven)

🚪

1 — Onboarding / Offboarding

Task checklists per employee type, document triggers, exit interviews. Uses existing Employee & User models.

🔔

2 — Notifications

In-app alerts + optional email. Supports onboarding task reminders + existing leave approval flows.

📋

3 — Surveys & Feedback

Pulse surveys, engagement scoring. Ties into Performance review cycle.

💼

4 — Asset / Expense Management

Company asset tracking (laptops, uniforms, tools). Expense claims with approval flow.

📊

5 — Advanced Analytics

Turnover reports, headcount trends, custom dashboards. Needs data from other modules.

Why this order

  • Onboarding is the highest-impact HR workflow missing from the system
  • Notifications are infrastructure that existing leave + new onboarding flows need
  • Analytics last because it benefits from accumulated data
  • Surveys and Asset management are independent — can be built in parallel

Trade-off

  • 5 features means a longer overall timeline vs picking one
  • Each sub-project still follows full spec → plan → code cycle
