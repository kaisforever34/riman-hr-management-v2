# Product

## Register

product

## Users

A single HR manager/owner at Riman Fashion (Sharjah, UAE) who handles everything — employee records, leave approvals, attendance tracking, payroll runs, document management, and performance reviews. No HR department. The system serves three roles (HR_ADMIN, MANAGER, EMPLOYEE) but the primary operator is the admin. Employees interact minimally: submit leave requests, view payslips, check attendance.

## Product Purpose

Replace manual/scattered HR processes with a single, polished system that covers the full employee lifecycle: onboarding (employee records), daily operations (attendance, leave), monthly cycles (payroll), compliance (documents), and quarterly evaluations (performance). Success means the manager can run the entire HR function for ~8+ employees from one dashboard without jumping between tools or spreadsheets.

## Brand Personality

Premium, Authoritative, Warm. The system should feel like a serious financial tool — trustworthy enough for payroll data, warm enough that employees don't dread interacting with it. Gold accents signal value and precision. The dark background communicates focus and sophistication, not "gamer aesthetic."

## Anti-references

- Default shadcn/ui look (white/gray cards, blue primary, generic table styling)
- Typical boring admin panels (overlined, flat, no visual hierarchy)
- SaaS cream/gray dashboard templates
- "Startup MVP" look — this is a production HR tool handling real payroll
- Overly colorful or playful designs — this handles serious data

## Design Principles

Dark authority — The dark background signals seriousness. Gold isn't decorative; it guides attention to actions and insights. Every visual choice reinforces trust in the data.

## Accessibility & Inclusion

WCAG 2.1 AA compliance. Sufficient contrast ratios on dark backgrounds. Keyboard navigable. Screen-reader friendly labels on all interactive elements.
