## PHASE 1: Schema Changes (Prisma)

### File: `prisma/schema.prisma`

**Employee model — add fields:**
- `gender String?` (options: Male, Female)
- `contractType String?` (options: FIXED_TERM, INDEFINITE, PROBATION)
- `contractStartDate DateTime?`
- `contractEndDate DateTime?`
- `probationEndDate DateTime?`
- `terminationDate DateTime?`
- `visaExpiryDate DateTime?`
- `iqamaNumber String?`
- `iqamaExpiryDate DateTime?`
- `basicSalary Float @default(0)` (WPS compliance)
- `housingAllowance Float @default(0)`
- `transportAllowance Float @default(0)`
- `otherAllowances Float @default(0)`
- Keep existing `salary` as total gross for backward compat

**AttendanceRecord model — add fields:**
- `overtimeMinutes Int @default(0)`
- `overtimeApproved Boolean @default(false)`
- `autoClockout Boolean @default(false)`
- `graceMinutes Int @default(0)` (grace period applied)

**Payslip model — expand fields:**
- `housingAllowance Float @default(0)`
- `transportAllowance Float @default(0)`
- `otherAllowances Float @default(0)`
- `overtimePay Float @default(0)`
- `bonusPay Float @default(0)`
- `gpssaEmployee Float @default(0)` (employee contribution ~5%)
- `gpssaEmployer Float @default(0)` (employer contribution ~12.5%)
- `eosbAmount Float @default(0)` (end-of-service benefit)
- `totalDeductions Float @default(0)` (computed sum)

**New model: OvertimeRecord:**
- `id String @id @default(cuid())`
- `employeeId String`
- `date DateTime`
- `minutes Int` (overtime minutes)
- `status String @default("PENDING")` (PENDING/APPROVED/REJECTED)
- `reason String?`
- `approvedById String?`
- `approvedAt DateTime?`
- `createdAt/updatedAt DateTime`
- `@@unique([employeeId, date])`

**New model: EosbRecord:**
- `id String @id @default(cuid())`
- `employeeId String`
- `terminationDate DateTime`
- `yearsOfService Float`
- `lastSalary Float`
- `eosbAmount Float`
- `createdAt DateTime`

**New AppSetting keys:**
- `GPSSA_EMPLOYEE_RATE` (default: "5")
- `GPSSA_EMPLOYER_RATE` (default: "12.5")
- `GRACE_PERIOD_MINUTES` (default: "5")
- `AUTO_CLOCKOUT_HOUR` (default: "21") — auto clockout at shift end + buffer
- `AUTO_CLOCKOUT_MINUTE` (default: "0")
- `MAX_CARRYOVER_DAYS` (default: "15")
- `MAX_CONSECUTIVE_LEAVE_DAYS` (default: "30")

### File: `prisma/migrations/` — new migration

Run `npx prisma migrate dev --name add-hr-compliance-fields` after schema update.

## PHASE 4: Attendance Fixes

### File: `src/lib/actions/attendance.ts`
- **checkIn()**: Use grace period from settings. Fix to support per-employee shifts
- **checkOut()**: Add overtime calculation — if employee worked past shift end, store overtimeMinutes on the record
- **New: submitOvertime()**: Employee/manager submits overtime for approval
- **New: approveOvertime()**: Manager approves/rejects overtime records
- **New: autoClockout()**: Called by a scheduled endpoint — finds employees who checked in but didn't check out before shift end + buffer, auto-creates checkout with `autoClockout: true`
- **markAbsent()**: Auto-detect employees with no attendance record at end of shift

### File: `src/lib/actions/payroll.ts`
- Complete rewrite for comprehensive payroll:
  - GPSSA employee contribution (5% of basicSalary)
  - GPSSA employer contribution (12.5% of basicSalary)
  - Overtime pay (approved overtime hours × hourly rate × 1.25 for normal, 1.5 for night/holiday)
  - Auto late deduction from attendance data
  - Salary breakdown: basicSalary + housing + transport + other = gross
  - EOSB calculation for terminated employees
  - Bonus from performance reviews (optional)

## PHASE 7: Payroll Fixes

### File: `src/lib/actions/payroll.ts` — FULL REWRITE
- `createPayrollPeriod()`:
  - Fetch employee salary breakdown (basic, housing, transport, other)
  - Calculate GPSSA deductions (employee rate × basicSalary)
  - Calculate overtime pay (approved OT × hourly rate × multiplier)
  - Calculate late deduction from attendance records (auto, not manual)
  - Calculate absence deduction (salary/30 × absent days)
  - Calculate transportation deduction (proportional to annual leave days)
  - Sum all deductions → totalDeductions
  - netPay = gross - totalDeductions
  - Store all breakdown fields on Payslip
- `recalculatePayslips()`: Recompute everything from current data
- **Remove**: `updateLateDeduction()` (now auto-calculated)
- `finalizePayroll()`: Same as before
